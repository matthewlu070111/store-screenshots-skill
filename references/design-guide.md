# 商店截图设计指南

## 先决定“讲什么”，再决定“好不好看”

商店截图不是 UI 展示墙，而是一条 5–10 秒内读完的产品故事。建议顺序：

1. **价值主张**：一句话说清“为什么值得下载”。（第 1 张）
2. **核心循环**：用户最常做的一件事，展示真实界面。（第 2 张）
3. **差异化**：别人没有的体验/数据/工作流。（第 3 张）
4. **信任**：真实评分、奖项、媒体引用、用户数量（必须真实）。（第 4 张，可选）
5. **补充**：多设备、离线、隐私、深色模式等。（第 5–8 张，可选）

不要把所有功能都塞进一张图；每张只讲一个点。

## 标题写法

好的标题：

- 3–10 个字（中文）/ 3–7 个词（英文），最多两行。
- 以用户收益为主语，而不是功能名。
- 具体、可验证，避免“颠覆”“最强”“第一”等空话。
- 与截图内容强相关；截图里看不到的功能不要写。

公式：

- **收益 + 场景**：`把注意力，留给重要的事`
- **动作 + 结果**：`一按开始，世界就安静了`
- **对比**：`更少打扰，更多心流`
- **数字/证据**：`21 天，养成专注习惯`（数字必须真实）
- **身份**：`为创作者设计的专注空间`

中文示例：

| 功能 | 弱标题 | 强标题 |
| --- | --- | --- |
| 番茄钟 | 番茄钟功能 | 25 分钟，做完最重要的一件事 |
| 白噪音 | 多种音效 | 一按开始，世界就安静了 |
| 统计 | 数据统计 | 看见每一次投入的积累 |
| 多设备 | 支持 iPad | 为更大的屏幕，做更少的打扰 |
| 连续记录 | 连续打卡 | 21 天，把专注变成习惯 |

英文示例：

- `Focus on what matters`
- `One tap. The world goes quiet.`
- `See every focused minute`
- `Built for the big screen`
- `Less noise. More flow.`

副标题：一句话补充“怎么做/适合谁”，不要重复标题。徽章：只放真实评分、真实下载量、真实奖项或平台认证。

## 版式选择

### `hero`

- 适合：首图、主功能、视觉强的界面。
- 标题在左上，设备从底部升起，底部自然裁切。
- 优点：稳定、转化率高、适合几乎所有品类。
- 注意：裁切位置不要切掉核心按钮/数据；首图优先。

### `split`

- 适合：深色模式、流程页、需要动感的第二/第三张。
- 设备带轻微旋转从右侧进入，文字在左。
- 优点：更有 editorial 感，适合强调“沉浸”“专注”“创作”。
- 注意：旋转+裁切会切掉右侧内容；不要把关键按钮放在最右侧。

### `minimal`

- 适合：工具类、单一功能、极简品牌。
- 标题居中，设备完整居中，留白多。
- 优点：干净、高级、缩略图下也清楚。
- 注意：对截图本身的完成度要求高；空白太多的 UI 会显空。

### `detail`

- 适合：有一个值得放大的控件/图表/数据。
- 在 `hero` 基础上加一个左下角特写卡片。
- 用 `detailFocus` 定位，`detailZoom` 控制倍率（1 = 原始像素）。
- 注意：特写会覆盖主图左下角；不要把主图关键内容放在那里。特写内容应与主图互补，而不是简单重复。

## 主题选择

| 主题 | 适合 |
| --- | --- |
| `aurora` | 科技、AI、效率、开发者工具 |
| `midnight` | 专业工具、金融、深色模式 |
| `sunset` | 生活方式、健康、社交、内容 |
| `ocean` | 冥想、健康、旅行、清新工具 |
| `mono` | 极简、摄影、设计工具 |
| `paper` | 阅读、笔记、手账、教育 |
| `mint` | 健康、习惯、轻量工具 |
| `lilac` | 创意、女性向、生活方式 |

一套图只用一个主题，或同一色系的深浅变化。不要在 3 张图里换 3 种完全不同的气质。

## 设备与裁切

- 手机截图放进手机框；平板截图放进平板框；不要混用。
- 竖屏 UI 用竖屏画布；横屏 UI 用 `orientation: "landscape"`。
- `hero` 默认让设备底部超出画布，制造“进入屏幕”的感觉；确保核心内容在上 60–70%。
- `split` 默认旋转 -4°，右侧会有少量裁切；关键按钮不要贴右边。
- 如果截图本身有大量空白，换 `hero`/`split` 裁掉底部，或补一张信息密度更高的图。

## 字体与可读性

- 标题字号至少为画布宽度的 5–7%；缩略图下仍要能读。
- 标题与背景对比度至少 4.5:1；深色主题用白色/浅色文字。
- 中文不要用全大写/超宽字距；英文小标题可以用大写+字距。
- 中文一行 8–14 个字最舒服；英文一行 3–6 个词。
- 不要靠把字号缩到很小来塞长文案；宁可删字。
- 衬线字体（`font: "serif"`）适合阅读/生活方式；工具类用系统无衬线。

## iPhone Duo 与 App Preview

- Duo 的外屏是“快速查看”，内屏是“展开工作”。外屏截图优先放最短路径（一眼看到状态/开始按钮）；内屏截图放更完整的工作流。
- 内屏预设会加折痕效果；确保关键文字/按钮不要正好压在折痕上。
- 横屏 Duo 截图用 `orientation: "landscape"`。
- **App Preview 是视频**，不是截图。`iphone-duo-preview` 只生成 886×1920 / 1920×886 的静帧首帧/封面；不要把它当视频上传。
- 做正式 App Preview 时，用真实录屏（15–30 秒），首帧可以用本工具生成的海报。

## 多语言

- 德语/俄语/葡萄牙语通常比英文长 20–40%；标题要留余量。
- 阿拉伯语/希伯来语是 RTL，生成器会自动镜像文字与品牌区；逐张检查。
- 日文/韩文不要直接套用中文断行；用 `locale` 对象分别写。
- 每种语言单独检查：换行、截断、按钮文案、日期格式、货币/单位。
- 不要把英文文案硬翻成中文；母语审校优先。

## 合规与真实性

- 只展示真实存在的 UI 和功能。
- 评分/下载量/奖项必须真实可验证。
- 不要伪造系统通知、媒体 Logo、平台认证。
- 不要使用其他平台的商标或设备图。
- 不要在截图中展示敏感用户数据；用示例数据并做匿名化。
- 订阅/价格/免费试用信息必须与实际一致。
- 健康、金融、儿童类应用遵守对应地区的额外广告/截图规范。
